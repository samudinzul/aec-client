AEC Client bundles the following open-source libraries:

1.  WebRTC Audio Processing (AEC3 echo canceller + high-pass filter)
    Copyright (C) 2011 The WebRTC project authors
    Copyright (C) 2011 Google Inc.
    License: BSD 3-Clause

2.  NKF-AEC
    "Neural Kalman Filtering for Acoustic Echo Cancellation"
    Jiang et al., ICASSP 2023
    License: MIT

3.  DTLN-AEC
    "Acoustic Echo Cancellation with the Dual-Signal Transformation
    LSTM Network"
    Westhausen & Meyer, ICASSP 2021 (breizhn/DTLN-aec)
    License: MIT (model weights + reference pipeline)

3b. DTLN noise reduction (DTLN-NS)
    Streaming speech enhancement, port of breizhn/DTLN denoise
    (networkedaudio/Realtime_AudioDenoise_EchoCancellation)
    License: MIT (upstream DTLN denoise)

3c. Hush noise suppression
    DeepFilterNet3 fork with a background-speaker auxiliary loss
    (pulp-vision/Hush — https://github.com/pulp-vision/Hush,
    model bundle https://huggingface.co/weya-ai/hush)
    License: Apache-2.0
    Bundled binaries: prebuilt weya_nc.dll (libs/) + ONNX bundle
    (models/hush_16k_onnx.tar.gz, upstream name
    advanced_dfnet16k_model_best_onnx.tar.gz — renamed: the release
    asserts ban any staged filename containing "dfn"),
    SHA-256 DLL 633958ef… / bundle 45632cca…; loaded at runtime
    with LoadLibrary (never linked), like tensorflowlite_c.

4.  ONNX Runtime
    Copyright (C) Microsoft Corporation
    License: MIT
    Bundled binary: official onnxruntime-win-x64 1.29.0 build
    (https://github.com/microsoft/onnxruntime/releases/tag/v1.29.0),
    uncompressed, SHA-256 69d8e6d3…; shipped together with the
    Microsoft VC++ 14 runtime (msvcp140/vcruntime140 — license:
    Visual Studio redistributable terms).
