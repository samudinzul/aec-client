About

aec-web

Version v1.11.0

A lightweight, open-source acoustic echo cancellation (AEC) client for Windows. Route your microphone through it and pick up a cleaned, echo-free signal in any app (Discord, Zoom, Teams, etc.). This copy runs as a pure-Python local server in a native window — no .exe, no installer, nothing for antivirus to flag.

Features
  • Three processing profiles (DTLN / WebRTC AEC3 / NKF-AEC) + DTLN-NS noise reduction (16 kHz)
  • Real-time processing with low CPU usage
  • Works with speakers, earphones, and headsets
  • Live level meters
  • Native app window (Edge WebView2) with browser fallback
