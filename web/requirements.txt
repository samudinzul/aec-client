# aec-web requirements — Python stack with one optional local accelerator.
# Install:  pip install -r requirements.txt   (Python 3.10+ on Windows)
#
# AV note: every package here is a mainstream, reputable wheel
# (Microsoft-scale reputation). The only binary of our own is the
# OPTIONAL aec_dsp Rust extension (ext/aec_dsp, built with maturin;
# see ext/README.md) — web/dsp.py falls back to NumPy without it.
# Do NOT freeze this into a PyInstaller/Nuitka exe — that
# reintroduces the exact problem this project exists to dodge.

uvicorn>=0.29         # ASGI server (run: python server.py)
websockets>=13        # WebSocket transport for uvicorn (meters would 404 without it)

ai-edge-litert>=2.2   # Google LiteRT: runs the .tflite DTLN pairs directly
pyaudiowpatch>=0.2.12 # PortAudio fork: mic in, WASAPI-loopback ref, CABLE out (single backend)

pystray>=0.19         # system-tray icon (minimize-to-tray; pure ctypes on Windows)
Pillow>=10            # draws the tray icon at runtime (mainstream wheel)
